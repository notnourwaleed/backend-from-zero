Backend from Zero

Learn how to build a real backend API in JavaScript — step by step, with no experience needed. You read a little, then you write the code yourself, right here in the page.

What you will be able to build

By the end you can build a travel API from an empty folder. It's a server that other programs (a website, an app) talk to. It keeps users, trips and reviews in a MySQL database:

RequestWhat it does
POST /auth/registerCreate an account (password stored safely with bcrypt)
POST /auth/loginLog in with email + password
GET /users, GET /users/:idRead users
POST / PUT / DELETE /users/:idCreate, change and delete users
GET /trips, GET /trips/:idRead trips (and remember the last one you viewed with a cookie)
GET /trips/reviewsJoin three tables: which user rated which trip

Once you can build this one, you can build the same thing for any topic: books, movies, events, a shop… Chapter 9 shows you how to change it to your own topic.

The golden rule

Every exercise has hints and a solution, and they are hidden on purpose. Try first. Being stuck for 10 minutes and then getting it teaches you much more than reading the answer. Open one hint at a time.

About the playgrounds

The code playgrounds run a simulator of Node.js + Express + MySQL inside your browser, so you can practise without installing anything. For everything in this course it behaves like the real thing. Still, always build the real project on your computer too — that's what the On your computer tasks are for.

Chapters

If you are completely lost right now

That's normal. Backend feels confusing because there are many new things at the same time: the terminal, Node, Express, SQL, async… This site separates them and teaches one thing at a time. Start with Chapter 0 even if you think you know it — it's quick, and it makes sure your computer is ready.
